## 二、开发经验

### 1. Next.js 水合问题
**问题**：Zustand + persist 中服务端和客户端 HTML 不匹配
**解决**：不使用 persist 持久化，手动在 useEffect 中处理 localStorage

```typescript
// 错误做法
const useStore = create(persist(...))

// 正确做法
const useStore = create((set) => ({
  user: null,
  setUser: (user, token) => {
    set({ user, token })
    if (typeof window !== 'undefined') {
      localStorage.setItem('keyi-user', JSON.stringify({ user, token }))
    }
  }
}))

// 恢复数据
useEffect(() => {
  const saved = restoreUser()
  if (saved) setUser(saved.user, saved.token)
}, [])
```

### 2. Supabase 邮箱验证
**问题**：开发环境邮件验证链接失效
**解决**：开发环境关闭邮箱确认（生产环境需开启）

```
Supabase 控制台 → Authentication → Providers → Email
取消勾选 "Confirm email"
```

### 3. SQLAlchemy 异步连接
**问题**：异步引擎需要正确的驱动
**解决**：使用 `asyncpg` + 正确格式的连接 URL

```python
# 正确格式
DATABASE_URL = "postgresql+asyncpg://postgres:password@host:6543/postgres"
```

### 4. UUID 类型处理
**问题**：Supabase 使用 PostgreSQL UUID，Python 需要转换
**解决**：

```python
from sqlalchemy.dialects.postgresql import UUID
import uuid

id = Column(UUID(as_uuid=True), primary_key=True, default=uuid.uuid4)

# 查询时转换
session_id = uuid.UUID(session_id)
```
